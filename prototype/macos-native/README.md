# 临时 macOS 原生录制实验

对应 [macOS 原生实验：能否满足干净录屏、独立双视频与短录同步？](https://github.com/benjamin-qhy/recordready/issues/4)。这是一次性能力原型，不是正式应用，也不是 Tauri 集成验收。问题涉及真实系统采集，HTML 模拟不能回答，因此使用原生可执行程序。

## 运行

需要 macOS 13+、Command Line Tools；当前实现只在实际运行的机器上验证，不据此保证最低版本兼容。

```sh
bash prototype/macos-native/run.sh
```

脚本编译当前架构、创建 ad-hoc 签名 `.app` 并启动。界面先不采集。点击“授权并预览”后通过 macOS 的相机、麦克风与屏幕录制授权；必要时在系统设置授权后退出并重新打开。开始前看清线框内内容，录制将包括该区域、默认相机和默认麦克风。程序不上传任何录音或视频。

选择 30 秒（保留的 30 分钟选项为可选工具，不再是必验项），点击开始，或随时“停止并保存”。再次录制生成新目录。录制中关闭窗口会先停止并保存，再次关闭才退出。

## 本实验固定值与可观察状态

- 主显示器中央的 16:9 区域（显示器点坐标），缩放至 1280×720、目标 30fps；不是最终选区交互。
- 摄像头会话请求 1280×720，但设备可能协商其他格式；writer 使用启动后实际 activeFormat 的画幅，实际输入/输出尺寸写入 `session.json`。不是相机最高质量验收。
- H.264/AAC MP4；单个麦克风设备产生的采样分别交给两个 writer，不承诺一次 AAC 编码。
- AppKit 透明穿透边框、可拖动提词窗口、原生预览窗口、独立控制窗口。ScreenCaptureKit 排除整个本应用。
- SCStream 与 AVCaptureSession 的采样时钟转换至 host clock，使用同一 epoch，保留首帧偏移；起点之前的整个音频包被丢弃，不做包内精确裁切。
- 原型提词为静态标记；不含正式滚动提词、设备选择、摄像头关闭、自定义尺寸、跨屏或 HDR 支持。
- 原型未验证 Tauri/WKWebView 与原生预览层的组合、硬件编码选中情况、签名公证及发布流程。

## 本地证据

`prototype/macos-native/artifacts/PROTOTYPE-<时间>-<唯一值>/`，已忽略，**不提交原始音视频或截图**：

- `screen.mp4`、`camera.mp4`：各自封装成功后由 `.partial.mp4` 改名。
- `session.json`：环境、设备、坐标、采样计数、首尾 PTS、背压丢弃和逐文件保存状态。
- `samples.jsonl`：各流前十个及每三十个样本的归一化时间戳。
- `memory.json`：每秒 RSS。
- `probe-state.json`：位于 artifacts 根目录，供自动化读取 UI/权限/会话状态。

```sh
python3 prototype/macos-native/analyze.py '<会话目录>'
```

需要 FFmpeg/ffprobe。检查文件流、实际尺寸、时长、全量解码及内存，并提取各视频 2 秒处一帧。`analysis.json` 中的结果不能证明真实音画同步。

可选动态参考图（独立进程，避免被本应用过滤器排除）：

```sh
bash prototype/macos-native/build-reference.sh
open 'prototype/macos-native/.build/RecordReady Capture Reference.app'
```

参考图与捕获区域重合，显示 host clock、移动色块、四角标记和网格。退出参考图使用 Command-Q。不产生音频，不模拟相机或麦克风。

更新 ad-hoc 签名的实验程序可能让 macOS 再次要求权限。先结束录制并退出旧版本，再重新打开并按系统提示授权；不要修改系统权限数据库。

## 评审步骤

1. 在线框底下打开动态内容，移动提词、相机和控制窗口，确认透明边框内部可操作别的应用。
2. 录制 30 秒，首尾各做一次可见且可听的拍手。检查屏幕文件不含粉色边框、提词、预览、工具窗，也没有遮挡后的黑块；相机文件只含完整相机画面。
3. 连续录制三次，检查每次两份文件可播放、没有覆盖。
4. 短录需保存首尾同步事件、实际测量方法与误差、内存记录。用户已取消 30 分钟长录要求。相机对拍手、屏幕对可见时间参考分别测量；不能只比较两条同源音轨或 PTS 起点就宣布 ≤200ms。
5. 用户评审样片与交互后再记录结论。缺少 Tauri 集成、Intel、macOS 13、混合 DPI/外接屏证据时，议题保持打开。

## 自动浮窗移动实验

当前临时版本在录制第 5–25 秒自动沿录制区域移动提词和摄像头窗，停止后恢复原位置；每秒记录真实窗口 frame、录制框和 host clock 到本地 `window-motion.json`。无需人工拖窗。此实验只验证程序移动时的窗口排除，不等于鼠标拖拽或正文穿透交互验收。

重新构建 ad-hoc App 可能触发系统重新授权。本次已通过系统设置刷新该实验的屏幕权限，摄像头/麦克风新授权提示须用户处理（自动化工具禁止操作 UserNotificationCenter）。收到授权后再开始 30 秒实验。正式开发仍需用户明确确认。

## 横竖屏 1080 尺寸实验

控制窗左下角可选「720 横屏」「1080 横屏」「1080 竖屏」，各录 30 秒；输出尺寸同步用于 SCStream 和屏幕编码器。准备时按输出比例重算居中的源区域，录制时锁定选择。相机仍保持实际输入画幅。独立 Reference 程序读取本地 probe-state.json 的区域尺寸以匹配参考图，区域变化后应先确认参考图就位再开始。

当前版本编译通过，仍有两处既有 Swift Sendable 捕获警告。新签名要求重新授权；在实际样片完成前，不声称两个 1080 档已通过。此功能仅存在于临时实验分支，不是正式开发。
