# 摄像头美颜与补光验证原型

Throwaway prototype：检验真实摄像头下的磨皮、瘦脸和方向性局部补光。用户最新要求已经移除虚拟背景。

```bash
bash prototype/camera-effects/build.sh
open 'prototype/camera-effects/.build/RecordReady Effects Probe.app'
```

构建要求 macOS、Apple Silicon、Xcode Command Line Tools。Metal 着色器通过系统运行时编译，无需额外安装离线 Metal 编译工具。最低部署目标为 macOS 13，当前实测设备是 M4 Pro / macOS 26.4。

首次运行按系统提示允许摄像头。磨皮、瘦脸和三个补光滑杆均为 0–100%，0 关闭。正面、画面左前、画面右前柔光可同时开启并独立调节，左右按输出画面定义。叠加亮度采用平滑上限和高光保护。补光跟随检测到的人脸，改善脸部亮度分布；它不重建实际三维光照。

程序显示实际输入尺寸、输出帧率、P95 处理耗时和丢帧计数。只有点击“录制 5 秒样片”才保存视频，原型不采集麦克风或屏幕。样片、JSON 指标和手动保存的画面位于 `~/Movies/RecordReady-Effects-Probe/`，不放入 Git。

`build.sh` 同时运行无需摄像头的 GPU 自检：原图旁路、正面提亮、左右光位、多光叠加与亮度上限、远处背景保护、无人脸关闭。真人观感仍需评审。

本原型尚不包含正式应用的双文件录制、暂停/恢复、配置持久化、设备选择、跨会话隔离与 Windows 后端。静态自检和单摄像头样片不能替代正式集成验收。

## macOS 系统效果与通用效果分离（2026-09-27）

启动默认关闭通用效果，优先通过“打开 macOS 摄像头效果”使用系统取景、摄影室灯光、屏幕补光、人像、背景替换和手势效果。人物居中提供 cooperative 模式开关，状态每秒同步系统。系统是否提供桌上视角等项目由设备决定；桌上视角是独立系统流程，不代表已接入录像。

“启用通用美颜与补光”独立控制原有磨皮、瘦脸与三方向补光，关掉时保留滑杆数值但绕过自定义处理。“重置通用效果”不更改系统设置。录样片时禁用应用内配置入口，但无法阻止用户从菜单栏改变系统效果。

通用算法与设置可以作为 Windows 后端的设计参考；当前实现仍使用 Swift、Vision、Metal，不是已经可在 Windows 执行的代码。Windows 需要实现关键点检测与 GPU 后端。macOS 的系统效果状态不应保存为 Windows 通用配置。

系统效果在采集上游应用，预览和录像消费同一帧；已实测系统背景替换进入预览，录制验收见测试记录。系统处理时间不包含在当前应用内 P95 指标中，该数字不能代表完整摄像头延迟。
