# RecordReady 升级操作原型

依据 [Screen Studio 对照体验与提升方案](../../Screen%20Studio对照体验与提升方案.md)，演示 B1–B4 的操作路径，供用户评审；不代表正式开发批准。

直接用浏览器打开 `index.html` 即可运行，无外部依赖。所有状态仅在内存中；刷新或“重新体验”重置。

可从仓库根目录启动预览：

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory docs/prototypes/recordready-upgrade
```

访问 http://127.0.0.1:4318/ 。

## 操作

1. 点击“准备录制”，确认相机与麦克风摘要。
2. 点击线框旁的输出按钮，体验竖屏、横屏、其他与自定义尺寸。
3. 点击提词设置调整字号/速度，编辑稿件或播放提词；拖动提词顶部可改变示意位置。
4. 点击保存位置；此处不再混入录制结果。
5. 开始模拟录制，倒计时后设备和输出锁定，主条精简；仍能调整提词和摄像头预览。
6. 停止后显示保存中，再呈现本次模拟文件结果；“再录一条”保留配置。
7. 用“静音 / 单文件”导览体验关闭相机和静音，仅产生一个模拟屏幕文件。

## 范围与验证

- 本轮通过浏览器实际点击检查：准备、输出分组与选中反馈、开始/倒计时、录制中精简与锁定、停止/保存中、双文件结果、静音/关闭相机后的单文件流程。
- 检查了 1440px 桌面视口与窄预览窗口。窄窗口缩放操作示意、将导览下移；它不是移动端产品设计。
- 摄像头画面为明确标注的示意区域，设备与电平为模拟数据；未请求任何权限、采集媒体或写入视频。
- 未模拟系统选目录对话框、原生鼠标穿透、选区四角缩放、设备热插拔、失败保存、完整英文界面和系统主题跟随。这些不能靠网页原型验收。
- 原型尚未收到用户评审，未将任何决策写入正式应用或 `design.md`。不作为产品级测试通过的证据。

当前文件为可丢弃的流程原型，原生应用与签名不受影响。
