# 视频平台尺寸调研

核查日期：2026-09-24。像素均为宽×高。区分普通投稿、广告投放、播放器展示和封面，避免混用规范。

## 官方来源及适用范围

| 平台 | 本次核查结果 | 对产品的影响 |
|---|---|---|
| YouTube | [官方分辨率说明](https://support.google.com/youtube/answer/6375112?hl=en)列出 16:9 的 1280×720、1920×1080、2560×1440、3840×2160；播放器也适配竖版等比例 | 横屏加入以上四档；不预先把黑边编码进视频 |
| TikTok | [信息流广告规格](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads?lang=en)覆盖竖版、横版和方形，优先竖版；这是广告规格 | 支持 9:16、16:9、1:1，不将广告门槛当普通投稿限制 |
| 微信视频号 | [腾讯广告 2025 创意指引](https://training.tencentads.com/uploads/202504/jfgt3GHS_IzrmFx.pdf)列出竖版 720×1280；[2023 广告资料](https://training.tencentads.com/uploads/202306/yOourto2_jqUnRH.pdf)出现过 6:7、1080×1260 | 纳入 720×1280；旧版 6:7 不作为当前默认，可自定义；广告材料不证明普通投稿的完整范围 |
| 抖音 | [上传 API 文档](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/upload/)有“16:9、1280×720、竖版”混合表述，方向描述不一致；[Android 分享接口](https://open.douyin.com/platform/resource/docs/develop/share/android)限制还取决于机型 | 不据此断言唯一推荐方向或所有入口的上限；提供横竖通用尺寸 |
| 快手 | [官方高清视频上传帮助](https://www.kuaishou.com/help/feedback/4000)说明上传后会转码，但该页未列出完整宽高预设 | 提供横竖通用尺寸，不承诺平台保留源分辨率 |
| B站、小红书、Instagram/Facebook | 本轮未取得足以确认当前普通投稿完整尺寸范围的官方说明；搜索结果中的用户帖子、封面规范和第三方汇总不作为硬性规格 | 不标记“平台官方推荐”；保留通用尺寸及自定义 |

## 实际采用的产品预设

- 9:16：720×1280、1080×1920（默认）、1440×2560、2160×3840。
- 16:9：1280×720、1920×1080（常用）、2560×1440、3840×2160。
- 其他：3:4 1080×1440、4:5 1080×1350、1:1 1080×1080、4:3 1440×1080。

以上是产品制作预设的并集，不是各平台逐项认证的规格表。竖屏高分辨率档由标准 9:16 比例推导；其他画幅用于构图选择，不宣称某个平台强制使用。不同平台、上传入口和账号能力可能不同。

保留每边 240–3840 偶数整数的自定义范围。8K 超出当前范围且不属于本期常用档，特殊超宽比例可自定义。原生实现应按实际编码能力验证或禁用不可用预设，不能仅凭 UI 可选即承诺可录制。录制区域小于输出尺寸时，放大不会产生新的源画面细节。
