# 六张已选设计稿校正说明

2026-09-25。逐张查看原 PNG 后制定。用户选择全部六张，跳过补画状态页；本次交付为原图配套的准确文字规范，未重绘 PNG、未实现正式界面。整体沿用橙色、浮窗、深色提词与虚化桌面展示。

| 顺序与证据 | 评估 | 定稿修正规则 |
|---|---|---|
| 1 [摄像头设置](01-camera-settings.png) | 设备、开关、镜像与位置层级清楚；提词初始状态易混淆 | 未开始提词时用“开始提词”；播放中才显示“暂停提词”。手动位置通过拖动预览实现；镜像明确只影响预览。 |
| 2 [声音设置](02-sound-settings.png) | 录音模式与电平清楚；双视频说明缺条件 | “同一音源写入两份视频”仅摄像头启用时显示；静音时电平停用并持续标记无音轨。摄像头位置和尺寸不随打开声音浮层变化。 |
| 3 [区域与尺寸](03-size-settings.png) | 十二项完整；合法值与报错同时出现 | 1080、1920 是合法输入，应无红色错误。仅无效提交时显示行内错误并保留已应用尺寸。合法与非法状态不可混在同一表单样例。 |
| 4 [稿件编辑](04-script-editor.png) | 编辑层级清楚；线框消失、提词放大、字数为示例 | 打开编辑器保留线框与提词位置/尺寸；窄屏采用避让。字数实时计算，不固定 86；7/50 不作为产品上限。 |
| 5 [中文浅色应用设置](05-app-settings-light-zh.png) | 三种外观与语言明确；工具条首项文字错误 | 文档图标旁恢复“编辑稿件”，另保留“回到开头”；两个入口不得合并。语言下拉分清触发器和菜单，收起时只显示当前语言。 |
| 6 [英文深色应用设置](06-app-settings-dark-en.png) | 保留中文稿件符合国际化边界；设置浮层锚点有歧义 | 应用设置锚定控制条齿轮，不能指向摄像头齿轮。补与浅色一致的关闭入口。Font 改 Font size；Start prompt 改 Start prompter；英文加宽而非缩小字号。 |

所有稿统一：准备状态用中性色；录制状态用红点加文字。橙色主按钮颜色、间距、圆角和文字对比度以 [design.md](../../../../design.md) 为准。图中的人物、设备名、壁纸均为展示素材。

可访问性与交互限度：这些静态稿可确认层级、位置和文字，但无法证明键盘焦点、读屏、鼠标穿透、真实录制排除与主题实时切换已正常工作。正式实现后必须验证。
