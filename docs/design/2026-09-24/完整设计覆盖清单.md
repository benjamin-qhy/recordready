“已有”仅指选中基底图可见内容，不代表功能实现；“待补图”不冒充完成。

| 设计页/状态 | 必须出现的元素 | 当前覆盖 |
|---|---|---|
| 准备主界面 | 状态、计时、线框四角/移动把手、尺寸入口、摄像头、麦克风电平、保存、开始 | 基底已有；需补回到开头、应用设置和明确控件名称 |
| 摄像头设置 | 设备下拉、开启/关闭、小窗/铺满、四角定位、手动位置、镜像预览及只影响预览说明 | 已有设置展开稿 |
| 摄像头关闭/无设备 | 隐藏预览但保留重新开启入口；找不到设备提示/重试 | 待补图 |

| 声音异常/静音 | 未授权、无设备、断开、静音持续标识；开始前处理与录制中中断区分 | 待补图 |
| 区域与尺寸 | 显示器选择、12 预设分组、自定义宽高/单位/应用、显示实际输出像素 | 已有设置展开稿 |
| 自定义错误/不可用 | 奇数/越界/空值就近报错、旧有效尺寸保留、机器不支持原因、录制锁定说明 | 已有自定义校验示例；机器不支持与录制锁定待补图 |
| 稿件编辑 | 标题、正文输入、字数、完成编辑、就近浮层不跳页 | 已有编辑展开稿 |
| 提词控制 | 字号、速度、开始/暂停/继续、回到开头；可独立移动且正文穿透 | 基底和稿件编辑稿已覆盖主要控件；独立移动/穿透待交互标注 |
| 保存位置 | 当前目录、选择目录、同会话双视频提示；系统目录选择器由系统提供 | 待补图；已有文件夹入口 |
| 应用设置（中文浅色） | 外观：跟随系统/浅色/深色；语言：简体中文/English；即时生效 | 已有展开稿 |
| 应用设置（英文深色） | 同一布局，Appearance: System/Light/Dark；Language；长英文适配 | 已有英文深色总览稿 |
| 倒计时/启动中 | 3 秒及取消；正在启动与录制中区分，未实际启动不计时 | 待补图 |
| 录制中 | 红点与文字/计时、停止、暂停提词、配置锁定、工具条聚焦恢复 | 待补图；不做录像暂停 |
| 保存中 | 真实写入/封装状态，禁用重复停止和再录一条，不假装可安全退出 | 待补图 |
| 全部保存 | 实际屏幕/相机文件、尺寸与时长、目录、打开文件夹、再录一条 | 待补图；仅录屏时只列一份 |
| 录制中断且已保存 | 原因、已保存中断前内容、各文件实际时长 | 待补图，与正常全部保存区分 |
| 部分保存/全部失败 | 成功和失败逐项展示，保留成功文件，错误与残留位置，明确确认 | 待补图 |
| 退出保护 | 继续录制/停止并保存；保存中等待；失败结果不静默消失 | 待补图 |
| 权限/目录/空间异常 | 缺权限、不可写、空间不足时阻止开始；录制中故障结束会话并尽力保存 | 待补图 |

相同结构的异常可共享组件，但每种文案和动作必须在状态稿/说明中可核对。不能把一张全部设置同时展开的总览当作可用主界面，也不能仅展示入口就宣布对应设置已设计完。

## 录制尺寸完整值

- 9:16：720×1280、1080×1920、1440×2560、2160×3840。
- 16:9：1280×720、1920×1080、2560×1440、3840×2160。
- 其他：3:4 1080×1440、4:5 1080×1350、1:1 1080×1080、4:3 1440×1080。
- 自定义：每边 240–3840 的偶数整数；明确应用。菜单存在不构成实际编码能力承诺。

## 新增外观和语言的检查项

外观默认跟随系统；浅色/深色为显式覆盖，选择应本地保存并跨浮窗同步。橙色强调色保留。深色不会改变桌面内容，也不会改变原始摄像头/录屏输出。提词正文允许在浅色 UI 中继续使用深底，保证阅读。

i18next + react-i18next 首期 zh-CN/en；系统初次选语言、显式偏好持久化、英文 fallback、无障碍标签/错误/通知翻译。用户稿件和文件/设备原名不翻译。中英主题切换不重建录制，不重置稿件位置或计时。
