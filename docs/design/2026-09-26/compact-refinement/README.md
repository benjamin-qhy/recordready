# Product Design：正式应用控件统一检查

本轮以现有正式桌面界面为依据，使用 CUA 捕获实际窗口，未修改网页原型。前后截图已打开并共同对比。

1. **设置浮层 — 通过。** 从320pt改为240pt，高度适配全部内容；移除差异化箭头，统一细边框与间距。
   - [调整前](01-settings-before.png) / [调整后](03-settings-after.png)
2. **保存位置 — 通过。** 从360pt改为240pt，与设置同宽同样式；说明换行完整显示，没有滚动条。长路径仍有完整提示。
   - [调整前](02-save-before.png) / [调整后](04-save-after.png)
3. **区域 — 通过。** 比例控件收窄，宽高默认显示、合法输入自动应用。无效和等待应用状态禁止开始录制。
   - [调整后](05-region-after.png)
4. **提词控件 — 通过，透明叠加效果有限验证。** 强制深色样式已移除，字号与速度统一加减/下拉；背景滑块可调整且不改变原生文字alpha。截图工具合成不透明底色，不据此断言任意桌面背景下的对比度。
   - [浅色工具条](07-prompter-light.png) / [背景45%状态](06-prompter-light-45.png)

可访问性检查仅包括控件名称、可选值、禁用状态和可见布局，不代表全面无障碍认证。用户正文未保存到截图。实际录屏仍沿用测试报告中的待验收限制。
