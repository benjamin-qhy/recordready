# RecordReady desktop

Mac 第一阶段正式工程。2026-09-25 用户授权开始；使用 Tauri 2、React、TypeScript、shadcn/ui（Radix）、Tailwind CSS、i18next，以及同进程 Swift 原生模块。

## 运行与验证

```sh
cd desktop
npm ci
npm run build
npm test
bash scripts/test-native.sh
npm run build:test-app
```

内部应用生成于 `src-tauri/target/debug/bundle/macos/RecordReady.app`，打开应用后点击“授权并预览”。macOS 的屏幕录制、摄像头与麦克风权限需按系统提示处理；这是新应用身份，实验程序权限不保证继承。正式应用未经过签名公证和发布验收。

测试构建必须运行 `build:test-app`：打包后完整签署应用包，并强制执行严格签名校验。编译器生成的 linker-signed 签名不能代替应用包签名。签名完成后固定本轮版本，授权和录制期间不得重建或重签。临时签名仍随构建变化，不能保证跨构建复用权限。

`npm run dev` 提供浏览器界面预览；浏览器禁止执行真实采集命令，不伪造成功文件。使用打包 `.app` 测试设备和权限，避免把开发终端的系统权限当作应用权限。

默认目录为 `~/Movies/RecordReady`；每次会话创建独立目录，屏幕和可选摄像头文件先写 `.partial.mp4`，封装成功后改名。原始录音录像不提交到 Git。

## 模块

- `src/App.tsx`：控制条与设置窗口，实际调用 Tauri commands；主题与语言偏好同步。
- `src-tauri/src/lib.rs`：异步 JSON C 桥接、窗口入口和退出保护。
- `native/CaptureEngine.swift`：由实验 `Main.swift` 提取的采集、统一时间戳、独立文件封装；增加可选摄像头、无音轨输出及设备故障通知。
- `native/Bridge.swift`：原生会话状态、倒计时取消、屏幕坐标转换、线框与提词窗口、相机预览；正文窗口鼠标穿透，把手独立接收输入。
- `native/NativeTests.swift`：不访问真实设备，检查会话保护、非法尺寸、配置原子性、空帧失败，以及真实 H.264 无音轨文件写入。

## 当前验证状态（2026-09-25）

已实现真实摄像头/麦克风/显示器选择，镜像、小窗、铺满、四角及归一化手动预览位置，就近设置浮层，独立提词工具条与区域尺寸入口；配置本地持久化。设置使用独立紧凑原生窗口，提词字号/速度使用系统菜单以避免紧凑 webview 裁切。

固定测试包已获本机授权，完成横竖 1080 和横竖 4K 实录。两份文件完整解码，屏幕固定 30fps 的逐帧间隔检查通过；固定帧率采用重复最近画面，不保证每帧是不同的采集画面。录制中 Command-Q 保护、停止保存后退出、提词拖动/穿透/滚动/暂停/复位已有实测证据。新增设置的中文浅色、英文深色和键盘关闭/焦点返回已检查。

前端测试、lint、TypeScript/Vite、原生无设备测试和 Tauri debug 构建通过；lint 保留两个 shadcn 组件 Fast Refresh 警告。异常注入覆盖设备错误、部分保存、同名文件不覆盖及全失败；不能替代实体断开和真实磁盘写满测试。

仍未完成完整验收：全部辅助窗口逐一入区后的排除覆盖、镜像与原片的人工对照、全部浮窗联合视觉、保存进行中退出、实体设备断开、真实磁盘写满、多显示器切换及物理音画同步。只有本机内建摄像头/麦克风，用户确认设备断开记录为未测。应用自有部分底层错误仍直接展示原始说明，错误详情本地化尚不完整。具体会话、构建身份、已修复问题与证据边界见 [集中测试报告](../docs/Mac第一阶段集中测试报告.md)。

构建配置的 macOS 13 是编译目标，不是已验证的最低支持系统。当前只开展本机 Apple Silicon 内部验证，尚未进入第二阶段或公开分发。
